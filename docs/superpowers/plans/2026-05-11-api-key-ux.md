# APIキー取得ガイド UX 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 非技術者ユーザー向けに、APIキーの取得手順と料金をモーダルで丁寧に説明し、メインUIをすっきりさせる。

**Architecture:** APIキーセクションから長い説明文を削除し、緑バッジ＋「取得方法を見る」ボタンに置き換える。ボタン押下で詳細モーダルを表示。バックエンドはWeb版を `gemini-3.1-flash-lite-preview`（無料モデル）に固定する。

**Tech Stack:** Vanilla HTML/CSS/JS、Python/FastAPI（server.py）

## Task 3: モーダル開閉ロジックをapp.jsに追加

**Files:**
- Modify: `web/app.js`

- [ ] **Step 1: `app.js` の末尾に以下の関数を追加する**

```javascript
// API Key Modal
function openApiModal() {
    document.getElementById('api-modal').classList.add('is-open');
    document.addEventListener('keydown', handleModalEsc);
}

function closeApiModal() {
    document.getElementById('api-modal').classList.remove('is-open');
    document.removeEventListener('keydown', handleModalEsc);
}

function handleModalEsc(e) {
    if (e.key === 'Escape') closeApiModal();
}

function handleOverlayClick(e) {
    if (e.target === document.getElementById('api-modal')) closeApiModal();
}
```
