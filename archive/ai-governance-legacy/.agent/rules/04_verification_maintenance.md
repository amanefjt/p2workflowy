# 04 検証と保守規約 (04_verification_maintenance.md)

## 1. 動作確認：ブラウザ拡張の義務化

UI の変更や階層構造の修正を行った際は、必ず **Antigravity Browser Extension** を使用して動作確認をします。

-   **エビデンスとしての Artifact**: 検証結果として、ブラウザのスクリーンショットまたは 操作録画（Browser Recordings）を提示し、視覚的な証明を行います。
-   **コンソールチェック**: JavaScript エラーが発生していないことを自律的に確認します。

## 2. リビングドキュメント：知的資産の継承

以下のドキュメントを `docs/management/` 配下に維持し、会話の節目で必ず追記・更新します。

-   **requirements_log.md**: ユーザーからの「こだわりポイント」や「仕様変更」を時系列または機能別に蓄積します。
-   **troubleshooting_log.md**: 発生したエラー、原因、解決策（コマンドやコード修正）、再発防止策を蓄積します。

## 3. セキュリティ：機密情報の保護

パスワードや API キーが含まれる可能性のあるファイル（.env 等）を扱う際は、`.antigravityignore` の設定を確認し、不必要な読み書きや外部露出を防ぎます。

## 4. 自律的な定義更新

重要な設計判断やルール決定が行われた際は、Mission (mission.md) や Rules (rules/*.md) への反映を自律的に提案し、プロジェクトの「記憶」を永続化させます。
