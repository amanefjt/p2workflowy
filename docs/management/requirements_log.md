# Requirements Log

- **2026-03-15**: 
    - **Workflowyフォーマットの厳守**: 生成される `.txt` ファイルは Workflowy のインポート形式（タブ + `- `）を完全に満たしている必要がある。
    - **不自然な行分割の抑制**: アカデミックな引用（コロンや `cf.` 等）によって、1つの文が複数の箇条書きに分割されるのを防ぐ。
    - **日本語翻訳の品質向上**: 書籍モードの翻訳において、見出しの整合性を保ち、未分類セクションを最小限にする。

    - **強制タイムアウトと自動復旧**: 応答が10分（600秒）を超えた場合はエラーとして検出し、自動的にリトライを行うことで、無期限の待機を防止する。
- **2026-03-15 (V2.9.8)**:
