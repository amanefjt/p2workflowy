# p2workflowy: 学術論文を「思考のツール」に変えるアウトライン・プロセッサー

> **学術論文のPDFテキストを、Workflowyに最適化された「構造化された日本語アウトライン」へ自動変換します。**

---

## 🌟 p2workflowy とは？

研究者や学生にとって、論文を読むことは「情報の海」を泳ぐようなものです。PDFからコピーしたテキストは改行がバラバラで、翻訳にかけても論理構造が崩れ、全体像を把握するのに多大な労力が必要でした。

**p2workflowy** は、このプロセスを劇的に変えます。
単なる「翻訳ツール」ではありません。論文の論理構造を解析し、整形し、あなたの Workflowy（アウトライン・プロセッサー）にそのまま貼り付けられる「思考の種」を生成する、パーソナルな論文読解アシスタントです。

---

## 🚀 主な機能

### 1. インテリジェントな「ノイズ除去」
PDFからコピーした際に混入する「不要な改行」「ページ番号」「フッター」などを自動で取り除きます。バラバラだった文章を、読みやすい自然な段落へと再構成します。

### 2. 文脈を読み解く「論理構造の抽出」
論文を「要旨」「導入」「手法」「結論」といったセクションごとに自動分離。Gemini AIが論文全体の流れを理解し、一貫性のある構造を作り上げます。

### 3. 指定した「専門分野」での高精度翻訳
「あなたは文化人類学の専門家です」といった役割をAIに与えることで、その分野特有の言い回しや専門用語を反映した翻訳を行います。分野は自由に変更可能です。

### 4. あなた専用の「用語集（Glossary）」対応
独自の用語集（CSV形式）をアップロードすることで、特定のキーワードを自分の好みの訳語で固定できます。AIが勝手に訳語をブレさせることはありません。

### 5. Workflowy への最適化出力
出力されるテキストは、Workflowyに貼り付けた瞬間に美しい階層構造（アウトライン）になるよう設計されています。そのまま思考を深め、メモを書き加えていくことが可能です。

## 🛠 使い方（プログラマー以外の方へ）

現在はローカルサーバー形式で動作します。

1.  **準備**: [Google AI Studio](https://aistudio.google.com/app/apikey) で無料の API キーを取得します。
2.  **起動**: ターミナルで `python server.py` を実行します。
3.  **操作**: ブラウザで `http://localhost:8000` を開きます。
4.  **変換**: 
    - 取得した API キーを入力します。
    - 専門分野（例：社会学、歴史学）を指定します。
    - 論文のテキスト（PDFをWordで開いてコピーするとより綺麗です）を貼り付けます。
    - 「変換を開始する」をクリック！
5.  **完了**: 生成されたファイルをダウンロードし、中身をコピーして Workflowy にペーストしてください。

## 💡 開発の裏側（Architecture Philosophy）

本ツールは、「LLMの不確実性をプログラムのロジックで制御する」という思想のもとに設計されています。

- **決定的な処理**: テキストの結合や正規表現による見出し抽出は Python が行い、AIには「要約」と「純粋な翻訳」のみを担当させています。これにより、AI特有の「勝手に内容を削る」「フォーマットを崩す」といった問題を最小限に抑えています。
- **スライディング・ウィンドウ方式**: 翻訳時に「直前の文脈」をAIに渡し続けることで、文章のつながりを自然に保っています。
