# 03 実装レシピとデバッグ・プロトコル (03_implementation_recipes.md)

## 1. 過去の教訓と再発防止レシピ (Debug Recipes)

以下の特定のバグは、修正済みの知見として「レシピ」レベルで管理します。

### **Recipe A: 見出しの「一字一句コピー」プロトコル (Verbatim Copy)**
- **問題**: SUMMARY 生成時に LLM が見出しを意訳・日本語化し、`match_heading` が失敗する。
- **対策**: プロンプトに **「角括弧内は一字一句、本文の見出しをそのまま（English）コピーせよ」** という厳格な Verbatim 指示を維持する。

### **Recipe B: 境界文字の保護 (Regex \b Fix)**
- **問題**: 正規表現で見出し番号を除去する際、`Introduction` が `ntroduction` に化ける。
- **対策**: ローマ数字や箇条書きの除去パターンには、必ず `\b`（単語境界）や `(?<=[.!?;:\"'])\s*` などの後方参照を組み込み、最初の文字の誤削除を防ぐ。

## 2. 性能と API の実測値 (Tier Settings)

安定稼働のための具体的なパラメータ（Paid Tier 用）：

-   **ラージ・バッチング**: **11,000文字 / 30チャンク**。
    -   細切れのバッチを避け、Gemini の「俯瞰能力」を最大化し、TTFT（思考時間）を抑制する。
-   **非同期リミッター**: `AsyncLimiter(100, 60.0)`。
    -   RPD（Requests Per Day）を考慮しつつ、スループットを最大化する実証済みセッティング。

## 3. ID の決定論的継承 (ID Stabilization)

フェーズを跨いで `TreeNode` の ID が「ドリフト」しないよう、インジェスト（Phase 1）時の `raw_text` に基づくハッシュ値またはシーケンスを、親から子へ（翻訳後も）継承し続ける。

## 4. サニタイズ・プロトコル (Safety)

ログやステートを保存する際、ファイル名から `:` や `\` などの特殊文字を強制的に除去し、OS レベルの書き出しエラーを未然に防ぐ。
