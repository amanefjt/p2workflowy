# p2workflowy V2.9.8 Stable Final Release (2026-03-15)

## 概要
書籍モード（Book Mode）および要約のみモード（Resume Only）を実用レベルまで完成させた安定版です。PDF構造解析の強化、APIタイムアウト対策、およびショートカットの利便性向上が図られています。

## 主要な改善点

### 1. 書籍モード (Book Mode) の安定化
- **構造解析**: 目次 (TOC) に基づく正確な章分割。
- **Resume Only 構成**: 「全体レジュメ + 章ごとの日本語要約 + 英語原文」という、学習・調査に最適なフォーマットを確立。
- **重複見出しの排除**: Workflowy出力時の `- English text` 重複問題を解消。

### 2. パフォーマンスと信頼性の向上
- **Phase 2 キャッシュ再利用**: すでに生成済みのレジュメがある場合、LLM呼び出しをスキップして即時に再開。
- **APIタイムアウト制御**: 10分以上の応答待ちをタイムアウトとして検出し、自動リトライを行うことで「見かけ上のハング」を防止。
- **ID衝突の防止**: 大規模書籍でもノードIDが衝突しないようオフセットを調整。

### 3. ショートカット (CLI 利便性)
- **`p2wbr`**: 書籍要約モード専用ショートカット。
- **対話的入力**: 引数なしで実行した場合にパス入力をプロンプトで表示。
- **引用符自動クレンジング**: パス貼り付け時に含まれる `'` や `"` を自動で除去（Macのドラッグ＆ドロップに対応）。

## 運用上の注意
- ショートカットの変更を反映するには `source ~/.zshrc` が必要です。
- 無料ティア/低ティアモデルでも安定して動作するように調整されています。
