# [Knowledge Base] PDFノイズ除去とチャンク化のヒューリスティクス
Phase 1 (Ingest & Preprocess) の実装仕様として以下のルールセットを厳格に適用すること。

## 1. 初期クレンジングルール（Basic Cleansing）
改行コードの正規化: \r\n および \r をすべて \n に置換する。

行またぎのハイフン結合: 単語の途中で改行されたハイフンを正規表現 r"(\w)-\n(\w)" で検出し、ハイフンと改行を削除して結合する（置換後: \1\2）。

## 2. フォーマット自動判定（Format Detection）
PDF のテキスト抽出結果には2パターンあるため、以下の中央値（Median）ロジックで判定する。

処理: 空行（\n\s*\n）の有無を調べ、全行の文字数の中央値を計算する。

判定 A one_line_per_paragraph: 中央値が 100 文字以上、または空行が全く存在しない場合。

判定 B wrapped_paragraphs: 上記以外の場合（文の途中で改行が入っている状態）。

## 3. 段落の再結合ルール（Smart Unwrap Heuristics）※最重要
フォーマットが wrapped_paragraphs の場合、以下のルールで「現在の行」と「次の行」を結合し、1つの段落に復元する。

結合しない（改行を維持する）条件:

次の行がインデント（スペース2つ以上）で始まっている場合。

文末判定（引用対応）: 現在の行の末尾が文の終わりを示す記号（. ! ? ; : " '）であり、その直後に引用ブラケットが続くケースも含めて文末とみなす。

実装用正規表現: r"[.!?;:\"'](?:\[[\d,\s-]+\])?\s*$"。

結合する（Unwrap する）条件:

現在の行の末尾がハイフン（-）の場合（ハイフンを取り除いて結合する）。

次の行の先頭が小文字（lowercase）で始まっている場合。

現在の行の末尾がカンマ（,）である場合。

現在の行の最後の単語が以下の Trailing words リストに含まれる場合:
["the", "a", "an", "of", "in", "on", "at", "to", "for", "and", "or", "but", "with", "by", "from", "as", "is", "was", "were", "are", "has", "had", "have", "that", "which", "who", "whom", "this", "these", "those"]

## 4. チャンク化と不要行のフィルタリング（Chunking & Filtering）
段落として分割した後、前後の空白を strip() する。

ページ番号の除去: 正規表現 r"^\d{1,5}$" に完全一致する行（数字だけの行）は破棄する。

## 5. 用語保護付きの単語分割（Glossary-Aware wordninja）
スペースが欠落した癒着単語（例: epicTheLordoftheRings）を分離する際、専門用語（固有名詞・非英語語彙）の破壊を防ぐため、以下の3ステップを実装すること。

退避: ユーザー提供の静的な glossary.csv の英語キー（例: "Strathern", "chicha de jora"）を抽出し、対象テキスト内でプレースホルダー（例: __GLOS_0__）に一時置換して退避させる。

注意: Phase 2 で生成される動的なキーワードはこの時点では存在しないため、使用しないこと。

分割: 長さが異常な文字列（20文字以上のアルファベット連続など）に対してのみ wordninja.split() を適用し、スペースを補完する。

復元: プレースホルダーを元の専門用語に復元する。
