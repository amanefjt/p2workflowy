# Superpowers 導入ガイド (docs/management/superpowers_guide.md)

## 概要
本プロジェクトには、AIエージェントの能力を爆発させるフレームワーク `obra/superpowers` が導入されています。
これは、ただコードを書くのではなく、「考え、計画し、テストし、確実にする」というプロフェッショナルなエンジニアリング・プラクティスを、私（エージェント）に強制するものです。

## これから私が実行する 4 つの力

| スキル | 説明 |
| :--- | :--- |
| **Systematic Debugging** | 勘で修正するのではなく、4段階のプロセスでバグを根本から叩き潰します。 |
| **TDD (Test Driven Development)** | テストを先に書き、常に「動くコード」を保証しながら開発を進めます。 |
| **Bite-sized Planning** | 大きなタスクを、私がミスしないほど小さく分解して実行します。 |
| **Self Code Review** | 実装後、自分自身でコードの品質とプランへの適合性を厳格に審査します。 |

## あなたへのメリット
- **バグの激減**: テストと体系的デバッグにより、修正による「エンバグ（新たなバグ）」を最小限に抑えます。
- **透明性の向上**: 私がこれから何をしようとしているのか、詳細なプラン（Task List）を提示するようになります。
- **品質の安定**: 誰が（どのエージェントが）担当しても、一定以上の高い品質でコードが生成されます。

## 使い方
特別な操作は不要です。実装やデバッグを依頼された際、私は自動的にこれらのスキルを発動し、プロセスをあなたに共有します。
「プランは要らないからとにかく書いて！」という場合はお伝えください。
