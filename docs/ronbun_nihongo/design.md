# Design: RonbunNihongo

## 1. 目的（Rationale）
`p2workflowy` は Workflowy でのアウトライン構築に最適化されていますが、本機能「RonbunNihongo」は、Workflowy を経由せず、**「日本語の論文抄録を Markdown でストレスなく読み通す」** ことに特化した派生機能です。

## 2. 設計指針

### A. インターフェースの完全分離
- **背景**: 既存の `p2workflowy` ユーザー（Workflowy 派）にとって、不要なメニューが増えることは UX の低下を招く。
- **決定**: URL を `/ronbun` に完全に切り分け、HTML/JS ファイルを物理的に分けることで、既存環境への影響をゼロにした。

### B. シンプルな出力構成
- **背景**: 読むことに集中するため、原文（英語）やメタ的な要約（Resume）がノイズになる場合がある。
- **決定**: ユーザーのフィードバックに基づき、**「論文タイトル ＋ 本文の日本語訳」**のみを純粋な Markdown として出力する。

### C. ユーザーへの「優しさ」を重視したUX
- **背景**: テクニカルな Phase 名やログは、一般ユーザーに「難解・不安」な印象を与える。
- **決定**: 
    - ログを隠し、ざっくりとしたパーセンテージ（25%刻みなど）と親しみやすいラベル（「分析中」「翻訳中」）で進行を伝える。
    - 全UIを日本語化し、各ステップの意図を明確にした。

## 3. 技術的実装の工夫
- `phase5_export.py` のメインロジックを変更せず、出力バリエーションとして新関数 `generate_ronbun_nihongo_output` を追加。
- 翻訳エンジン（Phase 1-4）は共通のため、高精度な構造解析と整合性チェックの恩恵をそのまま受けることができる。
