# Gemini API ティア動的最適化 (Tier Optimization) 解説

## 目的
Gemini API の有料版（Paid）と無料版（Free）で大きく異なるレート制限（RPM/並列数）を自律的に検知し、実行環境に合わせて最高のパフォーマンスを引き出しつつ、混雑時や制限到達時には自動で速度を落として完走させる。

## 実装の詳細

### 1. ティア管理 (`llm_client.py`)
- **GeminiTier Enum**: `PAID`, `FREE`, `UNKNOWN` の3状態を定義。
- **TierManager**: 実行中のティア状態を管理するシングルトン。
- **オートダウンシフト**:
    - `call_gemini_async` 内で `429 RESOURCE_EXHAUSTED` エラーをキャッチした場合、`TierManager.downgrade()` を発動。
    - 以降の全リクエストは自動的に「無料版設定」へとフォールバックされる。

### 2. 動的パラメータ適用 (`phase4_translate.py`)
翻訳フェーズでは、現在のティアを監視し、以下の通りパラメータを即時切り替える。

| 設定項目 | PAID (標準/CLI) | FREE (Web/ダウンシフト後) |
| :--- | :--- | :--- |
| **Semaphore (並列数)** | 12 | 2 |
| **RPM Limit** | 500 (実質制限なし) | 15 |
| **Batch Size (チャンク)** | 20 | 10 |
| **Batch Max Chars** | 10,000 | 4,000 |

### 3. CLI/Web のデフォルト挙動
- **CLI**: デフォルトで `PAID` モードで開始（`--free` で強制指定可能）。
- **Web UI**: 安定性を考慮し、常に `FREE` モードの制限内で動作を保証。

## ユーザーへのメリット
- 有料ユーザーは、CLI を通じて大規模ドキュメント（10万文字超）を数分で翻訳可能。
- 無料ユーザーまたはレート制限に達した有料ユーザーでも、プログラムがクラッシュすることなく最後まで確実に翻訳が完了する。
